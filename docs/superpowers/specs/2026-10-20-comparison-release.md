# Stocklens comparison and stock pages

The user prioritizes an intuitive Home comparison, real quote coverage and visible listed/tokenized prices. Markets should open a stock overview inspired by the supplied references and support comparison of different stocks. Preserve the daylight Stocklens identity and the existing single Render service, free sources, no runtime dependencies, no custody and no transaction submission.

Home separates selecting token versions for legal/product terms from comparing live size-specific buy quotes. Successful routes lead; unavailable deployments remain inspectable with reasons. Quote provider and actual liquidity exchanges are distinct. Unknown share conversions remain unranked and expiry never creates a current offer.

Listed prices keep exchange, source and date/time precision. Representative normalized pool premiums are separate from size-specific buy premiums; closed-market comparisons say versus last close. Never divide an undocumented token-unit aggregate by a listed share price.

Markets gains listed prices and a five-stock selection tray. Clicking a company opens its stock detail page with overview, observed chart, company/tokenized metrics, issuer versions and networks. Stock comparison is distinct from Home's comparison of token versions. New pages have canonical URL state, browser back navigation, mobile layout, source disclosures, missing-data states and retries.

Verify with meaningful regressions and actual provider/application HTTP tests, followed by desktop/mobile browser checks through CUA. Public deployment must pass CI and then the same real core flows. Broad source availability is not promised.
