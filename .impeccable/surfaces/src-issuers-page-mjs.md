# Issuer landscape and data rooms

Mode: Operate. Visitors compare tokenized-equity issuers and inspect a specific issuer's mapped assets, reported token market metrics, networks and legal documents. The primary action opens an issuer, then a security in Compare with that issuer selected.

Inherit Stocklens's forest/mint palette, real marks, saved light mode and open canvas. Horizontal market-share bars and a full-width ranking replace dashboard cards. The data room uses open metric columns, searchable assets, network-presence rows and readable terms. One short bar reveal communicates data arrival; reduced motion removes it. No fabricated history or decorative chart.

Market-share denominator, reporting coverage and source dates stay visible. Financial aggregates cover CoinGecko's issuer-token universe; mapped coverage uses the canonical catalog. Unclassified securities retain an explicit category; wrapped versions are separate and opt-in, with wrapped-only issuers opening their wrapped list. Network metrics are counts, never inferred market-cap allocation. Missing reports remain missing. Source and methodology disclosures explain these differences.

Phone tables scroll within labeled regions with a sticky identity column and a swipe hint. Search, network/type filters, pagination, CSV, source links, retry and browser history must remain usable. No new paid API or runtime dependency.
